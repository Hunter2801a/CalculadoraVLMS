# Calculadora VLSM

Herramienta para subnetear con VLSM. Se escribe la red y los hosts que necesita cada subred, y devuelve el desarrollo paso a paso.

Sitio estático en HTML, CSS y JavaScript vanilla, sin dependencias ni build.

## Uso local

Abrir `index.html` en el navegador.

## Estructura

- `index.html`: estructura de la página
- `styles.css`: estilos (incluye modo oscuro)
- `app.js`: lógica de cálculo y renderizado
- `favicon.svg`: ícono

## Deploy

Se despliega en Vercel como sitio estático (Framework Preset: Other, sin build command ni output directory).
